# Network Inventory (PowerShell + WPF)

Инвентаризация компьютеров локальной сети: сканирование, карточки устройств,
табличные отчёты, учёт ПО и лицензий, журнал изменений между сканированиями.

## Требования

- Windows 10/11 или Windows Server 2016+, **Windows PowerShell 5.1** (встроен в систему)
- .NET Framework 4.5+ (встроен)
- Для сканирования удалённых компьютеров: учётная запись с правами администратора на них и
  доступ по **WinRM** (рекомендуется, `Enable-PSRemoting -Force`) или **WMI/DCOM** (порт 135 + RPC).

## Запуск

Дважды щёлкните `Запустить.cmd`, или из консоли:

```
powershell -NoProfile -ExecutionPolicy Bypass -STA -File .\Start-NetInventory.ps1
```

Для полного сбора данных о локальном компьютере (TPM, BitLocker, SMART) запускайте от имени администратора.

## Где хранятся данные

- Хранилище (по умолчанию `Документы\NetInventory Storage`): папки хранилища = папки на диске,
  каждое устройство — файл `*.device.json`, история снимков — в скрытой папке `.data`.
- Настройки, логины (пароли зашифрованы DPAPI), сохранённые задачи и журнал ошибок —
  `%APPDATA%\NetInventory`.

## Структура

| Папка / файл | Назначение |
|---|---|
| `Start-NetInventory.ps1` | точка входа |
| `src\Collector.ps1` | сбор данных (CIM/WMI, реестр); используется и автономным сборщиком |
| `src\Scanner.ps1` | разбор задач, обнаружение узлов (ping, ARP, порты), параллельный сбор |
| `src\Storage.ps1` | хранилище JSON |
| `src\Software.ps1` | учёт ПО и лицензий |
| `src\Changes.ps1` | сравнение снимков |
| `src\Reports.ps1` | шаблоны табличных отчётов |
| `src\CardView.ps1` | содержимое карточки устройства |
| `ui\*.xaml`, `ui\*.ps1` | интерфейс WPF |

## Автономный сбор

Меню «Инвентаризация → Создать автономный сборщик» сохраняет `Collect-Inventory.ps1/.cmd`.
Запустите его на компьютере без сетевого доступа, а полученный `.json` импортируйте через
«Хранилище → Импортировать».
